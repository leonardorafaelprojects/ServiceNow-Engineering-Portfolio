# 🚀 Leonardo Rafael - ServiceNow Engineering Portfolio

Bem-vindo ao meu ecossistema central de projetos focado no domínio técnico e arquitetural da plataforma **ServiceNow**. Este monorepo centraliza toda a minha jornada de desenvolvimento prático, partindo dos fundamentos até a arquitetura de soluções corporativas.

## 🗂️ Arquitetura do Repositório

Este ecossistema está dividido estrategicamente em duas frentes de atuação para facilitar a auditoria de código e a governança:

### 1. 🏢 Nebula Cloud Dynamics (`/nebula-cloud-dynamics`)
A Nebula é a minha "Empresa Fictícia" e laboratório vivo. Aqui aplico conceitos de arquitetura técnica, ITSM e automação para resolver problemas complexos e simular regras de negócios do mundo real.
* **Foco Arquitetural:** Modelagem de Dados, Governança de Instância, Segurança (ACLs), Flow Designer e Integrações.

### 2. 📘 Now Pro Labs & Homeworks (`/nowpro-labs`)
Espaço dedicado para a engenharia reversa e documentação de todos os laboratórios e *homeworks* práticos da formação avançada **Now Pro**. Este braço do projeto serve como um *playbook* de soluções arquiteturais e preparação para certificações oficiais (CSA, CAD).
* **Foco Técnico:** Service Catalog, UX Front-end (UI Policies), Componentização (Variable Sets), Client & Server Side Scripts.

## 🎯 Minha Missão como Desenvolvedor
Acredito que o verdadeiro valor de um profissional ServiceNow não está apenas em "construir aplicações", mas em desenhar **arquiteturas sustentáveis e escaláveis**. Minha missão neste repositório é documentar o *porquê* de cada decisão técnica, aplicando incansavelmente *Best Practices* do mercado, tais como:

* **DRY (Don't Repeat Yourself):** Foco em componentes reutilizáveis (ex: Variable Sets) para facilitar manutenção.
* **Clean UI/UX:** Regras de interface no cliente (UI Policies) para otimizar a experiência do usuário final.
* **Governança Estrita:** Separação clara entre *Instance Configuration* e *User Personalization*, garantindo upgrades seguros.
