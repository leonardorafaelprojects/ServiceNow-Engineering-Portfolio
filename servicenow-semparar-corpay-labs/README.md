\# 🏎️ ServiceNow Engineering Portfolio - Sem Parar (Corpay) ![ServiceNow](https://img.shields.io/badge/ServiceNow-Washington%2FXanadu-green?logo=servicenow) ![Platform](https://img.shields.io/badge/Architecture-Low--Code%20%2F%20No--Code-blue) ![Governance](https://img.shields.io/badge/Governance-Update%20Set%20Managed-orange) ![License](https://img.shields.io/badge/License-MIT-brightgreen) ## 📌 Sobre Este Repositório Este repositório reúne as \*\*soluções de engenharia, governança de dados e automações de processos\*\* desenvolvidas para cenários reais da operação do \*\*Sem Parar (Corpay)\*\* na plataforma ServiceNow. O objetivo principal é demonstrar a aplicação prática do princípio \*\*"Configuration over Customization"\*\*, construindo fluxos de autoatendimento agéis, validações client-side robustas e automações sem código que suportam a operação de frotas e serviços corporativos. --- ## 🏛️ Índice dos Laboratórios &amp; Soluções | Módulo / Lab | Domínio Técnico | Tecnologias Chave | Status | | :--- | :--- | :--- | :---: | | \*\*[Lab 01: Service Portal &amp; Client Governance](./lab-01-service-portal-client-governance)\*\* | Frontend &amp; Validações | Record Producer, UI Policies, \`g\_form\`, \`g\_user\`, Update Sets | 🟢 Concluído | | \*\*[Lab 02: Flow Designer Tag Approval](./lab-02-flow-designer-tag-approval)\*\* | Automação de Processos | Flow Designer, Data Pills, Ask for Approval, Service Catalog | 🟢 Concluído | | \*\*Lab 03: Gestão à Vista &amp; Dashboards\*\* | Analytics &amp; Relatórios | Report Builder, Interactive Filters, Performance Analytics | 🟡 Em Breve | | \*\*Lab 04: Governança de Tarefas &amp; Task Engine\*\* | Arquitetura de Dados | Task Table Extension, Data Policies, Dictionary Overrides | 🟡 Em Breve | --- ## 🛠️ Padrão de Governança e Qualidade Todos os laboratórios contidos neste repositório seguem rigorosamente as seguintes boas práticas de engenharia ServiceNow: 1\. \*\*Versionamento via Update Sets:\*\* Nenhum desenvolvimento é realizado diretamente em produção ou sem rastreabilidade. Todo artefato possui seu arquivo \`.xml\` exportado na pasta \`update\_sets/\`. 2\. \*\*Arquitetura Low-Code First:\*\* Priorização de recursos nativos (\*Out-Of-The-Box\*) como UI Policies e Flow Designer para garantir a sustentabilidade do código durante os upgrades da plataforma. 3\. \*\*Protocolo de Testes UAT/QA:\*\* Matriz de testes executada simulando perfis reais de usuários do negócio (\*Impersonation\*), garantindo a qualidade sem o uso de privilégios de \`admin\`. --- ## 👤 Autor \* \*\*Leonardo Oliveira\*\* - \*ServiceNow Administrator &amp; Low-Code Developer\* \* \*\*LinkedIn:\*\* [Seu Perfil no LinkedIn] \* \*\*GitHub Main Portfolio:\*\* [ServiceNow-Engineering-Portfolio](https://github.com/leonardorafaelprojects/ServiceNow-Engineering-Portfolio)
